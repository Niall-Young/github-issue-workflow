# Orca Autopilot Plugin & Terminal TUI Instructions (`orca-plugin/`)

## Scope

`orca-plugin/` contains the zero-dependency pure terminal Orca Autopilot TUI (`src/tui/`) plus a minimal Orca `trusted-worker` plugin (`src/worker.ts`) for status-bar pending badges, desktop notifications, and launching the TUI in an Orca terminal tab.

## Local Rules

- Never edit files inside `.orca/` (generated by `orca plugin types` and ignored by Git).
- Keep the TUI and plugin free of external runtime npm dependencies; use only Node/Bun built-ins, Orca host APIs, and local CLIs (`orca`, `gh`, `sqlite3`, `python3`).
- Write tests in `node:test` (`node:assert/strict`) so `orca plugin test` runs both data-layer and TUI tests.
- Validate every change with:
  ```sh
  orca plugin validate ./orca-plugin --json
  orca plugin test ./orca-plugin --json
  orca plugin check ./orca-plugin --json
  ```
