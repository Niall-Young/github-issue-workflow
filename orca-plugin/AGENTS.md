# Orca Plugin Instructions (`orca-plugin/`)

## Scope

`orca-plugin/` is an independent Orca `trusted-worker` + `customEditor` TypeScript plugin that renders a per-project Issue Board inside Orca's main editor area.

## Local Rules

- Never edit files inside `.orca/` (generated by `orca plugin types` and ignored by Git).
- Keep the plugin free of external runtime network requests and native npm dependencies; use Orca host APIs and local CLIs (`gh`, `sqlite3`, `python3`).
- Validate every plugin change with:
  ```sh
  orca plugin validate ./orca-plugin --json
  orca plugin test ./orca-plugin --json
  orca plugin check ./orca-plugin --json
  ```
